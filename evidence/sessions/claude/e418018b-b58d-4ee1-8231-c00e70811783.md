**Alfred —** It works like a small library with a front desk. Claude Code reads the front desk file first, then opens only the shelf you ask for.

**How it gets loaded.** Every skill in the lab's skills folder has a name and a one-line description. When you say `godin-purple-cow`, or ask something the description matches (sneezers, otaku, "is this a brown cow?"), Claude Code loads the master file. That file is about 2,300 words, so it costs little.

**What the master file holds.** Three things:

- The core frameworks, in about 800 words. Enough to apply the book without opening anything else.
- A chapter index and a topic index. "Sneezers" points to chapters 4 and 9. "Cheap" points to 10 and 12.
- Links to three helper files: glossary, patterns, cheatsheet.

**What happens on a question.** Say you ask "should we cut price on Telegraph?" I read the core section, see "cheap" in the topic index, open chapter 10, and answer from Godin's actual argument (cheap is lazy unless you leap the cost structure), quoting it. I never open all twelve chapters. Only the ones the question needs.

**The three helpers.** The cheatsheet is for judging something fast: a table of "when this, do that, because." Patterns are the twenty-two techniques with when, how, and trade-offs. The glossary is for a term you half remember.

**What it does not do.** It holds the book only. It does not know your voice, your audience, or Telegraph. For those it leans on the brand files, and the master file says so at the bottom.

**Try it:** type `/godin-purple-cow` and then a question, or ask "is the morning brief a brown cow?"
