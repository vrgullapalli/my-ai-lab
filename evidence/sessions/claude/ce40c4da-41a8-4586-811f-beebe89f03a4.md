**Context Builder** ([github.com/igorls/context-builder](https://github.com/igorls/context-builder)) — a command-line tool that packs a whole project folder into one markdown file you can paste into an AI chat.

- **What it does:** run one command in a folder, get `output.md` with all your files inside, ordered so an AI reads the important ones first (config and docs first, then source, tests last).
- **Problem it solves:** the copy-paste grind of feeding files to ChatGPT, Claude.ai web, or Gemini one at a time.
- **Nice touches:** respects `.gitignore`, skips heavy folders like `node_modules`, can cap output by token count (`--max-tokens`), filter by file type.
- **Maturity:** small but active — 34 stars, ~91 commits.

**Do you need it?** Probably not for this setup:

- Claude Code (what we're in now) already reads your files directly — no packing needed.
- Where it *would* help: pasting your repo's context into a chat that can't see your disk — Claude.ai web, ChatGPT, or Gemini. If you do that often, it saves real time.
- One caution: the install is `curl | bash` (runs a script straight off the internet). Fine for a small tool, but worth knowing before installing.
