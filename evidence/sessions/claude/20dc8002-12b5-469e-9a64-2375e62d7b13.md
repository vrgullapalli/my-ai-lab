> ## Troubleshooting â€” Known Issues & Fixes
> 
> These are real problems we hit during development. If Claude gets stuck on any of these, point it to the fix.
> 
> ### "Model not found" or model errors
> **Problem:** The Claude API rejects the model ID.
> **Fix:** Use `claude-sonnet-4-5` as the model. Other model IDs (like `claude-opus-4-5` or version-suffixed names like `claude-3-5-sonnet-20241022`) may not work with direct browser access. If you get a model error, try `claude-sonnet-4-5`.
> 
> ### Google OAuth shows "invalid_client" (Error 401)
> **Problem:** When clicking "Connect Google Account", Google shows "The OAuth client was not found."
> **Fix:** The Client ID entered in the app doesn't match the one in Google Cloud Console. Double-check the Client ID is copied exactly â€” the full string ending in `.apps.googleusercontent.com`. Also ensure the Authorized JavaScript Origin matches the URL you're loading the app from (e.g., `http://localhost` for local, or your Netlify URL for deployed).
> 
> ### Google OAuth shows "Access blocked" (Error 403)
> **Problem:** Google says the app is blocked or the user isn't authorized.
> **Fix:** The app is in Testing mode. Every Google account that needs access must be added as a Test User in Google Auth Platform â†’ Audience â†’ Test Users. Add the exact Gmail/Google Workspace email address.
> 
> ### Google OAuth auto-selects the wrong account
> **Problem:** The Google sign-in popup picks an account automatically without letting the user choose.
> **Fix:** Add `prompt: 'select_account'` in two places:
> 1. In the `initTokenClient()` config object
> 2. In the `requestAccessToken()` call: `requestAccessToken({prompt: 'select_account'})`
> 
> ### File upload doesn't work on re-select
> **Problem:** Selecting the same file again after clearing doesn't trigger the upload.
> **Fix:** Reset the file input before opening the picker: `input.value = ''` before calling `input.click()`.
> 
> ### App works locally but not when deployed
> **Problem:** Everything works from `file://` or `localhost` but breaks on the public URL.
> **Fix:** You need to add the deployed URL as an Authorized JavaScript Origin in Google Cloud Console. Go to Google Auth Platform â†’ Clients â†’ your client â†’ add the full URL (e.g., `https://your-site.netlify.app`). Changes can take 5 minutes to propagate.
> 
> ### Google Doc creation fails with 401
> **Problem:** Content generates fine but the Google Doc step fails.
> **Fix:** The Google OAuth access token has expired (they last ~1 hour). The app should have a "Reconnect Google" button that re-authenticates and retries doc creation without re-running the Claude API calls.
> 
> ### localStorage gets cleared between sessions
> **Problem:** User has to re-enter API keys every time they open the app.
> **Fix:** This happens if the browser is in Private/Incognito mode (localStorage is wiped on close) or if the user cleared their browser data. Use a regular (non-private) browser window.
> 
> ### CORS errors on Claude API calls
> **Problem:** Browser blocks the Claude API request.
> **Fix:** Make sure the `anthropic-dangerous-direct-browser-access: true` header is included in every Claude API request.
