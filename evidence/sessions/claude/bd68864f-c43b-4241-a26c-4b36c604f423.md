Short version: the prompt you pasted is not a `/loop` job, and you already own the skill that's closest to it. Here is what I found.

## What `/loop` actually is
- `/loop` runs a prompt **on a timer** (every 5 minutes, or self-paced). It is for polling — "check the deploy every 5m".
- Your example is a different shape: **one task, iterate until a rubric passes, bounded retries**. That is a correction loop inside a single run, not a schedule.
- `ralph-loop` is closer (feeds the same prompt back until a completion promise is true), but it has no rubric, no retry caps, no scope fence. You would still write the whole prompt.

## What you already have
- `~/.claude/skills/loop-contract/SKILL.md` — built 2026-08-03 — is exactly this: triage, contract (done / stop / budget / blast radius), approval, launch, debrief. Your example prompt is a hand-written loop contract.
- Its gap: v1 is **code loops only** (pytest/ruff/mypy as the checker). Non-code rubrics like your 14-point commit check are marked "v2, deferred" ([SKILL.md:29](../../../.claude/skills/loop-contract/SKILL.md#L29), [:116](../../../.claude/skills/loop-contract/SKILL.md#L116)). So it would route your example to SUPERVISED and not help.
- It is also heavy (7 preconditions, two file copies, blocking sign-off). That fights Rule 1 for a Class 1 commit.

## What `writing-skills` says about this
- Create a skill when the pattern is reusable and not obvious. Yours is: outcome → scope fence → hard PASS rubric → bounded corrections → post-check → report-only return. That recurs.
- Its method is TDD: run the task without the skill first, record how the agent drifts, then write the skill against those drifts. You already have baseline evidence — the prompts you keep rewriting.
- It says: if a constraint can be checked mechanically, automate it, don't document it. Parts of your rubric (staged path list, `diff --check`, no secrets) can be a script; only the judgment parts need prose.

## My recommendation (one default)
- Don't build a new skill. **Add a "bounded task" template to `loop-contract`** — a light mode for Class 1 work: no triage record, no two copies, just the six sections your prompt already has, filled from a few questions.
- That keeps one loop skill (D-009: no parallel trackers) and lifts the non-code-rubric gap it already names as v2.
- It is a change to how agents behave, so under D-137 it is Class 2: needs a short plan with three options and your approval before anything is written (rules 15–17).
