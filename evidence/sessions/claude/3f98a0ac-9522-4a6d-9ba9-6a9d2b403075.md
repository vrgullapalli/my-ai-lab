**2. What connective architecture was missing** — four gaps, none a store:
- Impact analysis is defined only at the source-intake entry. Internal events have no defined "what else does this change?" step.

**3. The proposed shared learning contract** — twelve questions every participating capability must answer about a learning-bearing record. Four are new and are exactly the missing tissue: **learning status, affected areas, proposed destination, authority required**. Scores, embeddings, and retention fields were explicitly refused. Not a schema, not a store.

**4. The end-to-end loop** — Venkat's 14-stage flow adopted as a behavioral contract, each stage mapped to an existing owner and mechanism with status. Explicitly not a software pipeline; stages may be satisfied manually.

**5. Local versus shared ownership** — durable learning lives with its canonical owner (procedural → function home; governing → decision path; memory → memory owner; relationship → scoped contexts; evidence → R-15; work-state → work object; health → health state).
