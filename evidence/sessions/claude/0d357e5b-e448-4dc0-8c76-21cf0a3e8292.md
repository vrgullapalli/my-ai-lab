`★ Insight ─────────────────────────────────────`
- Claude Code stores MCP servers in `~/.claude.json` at three scopes: **local** (you + this project), **project** (`.mcp.json`, checked into the repo for teammates), and **user** (all your projects). Dropbox is a personal account connection, so local or user scope fits; project scope would push your connector onto anyone cloning the repo.
- The `--transport http` flag matters: older MCP servers used stdio (a local process) or SSE. Dropbox runs a remote HTTP server with OAuth, so nothing gets installed on your machine — Claude Code just calls their endpoint with your token.
