> ## Core distinction
> 
> For every material system capability, function, workflow, or proposed architecture element, classify it as one of:
> 
> ### 1. Automation
> 
> Existing capability → existing application → existing outcome, delivered more efficiently.
> 
> Examples include faster execution, lower cost, fewer errors, easier coordination, or reduced manual effort.
> 
> ### 2. AI-native redesign
> 
> Existing objective → materially redesigned application or workflow → materially better version of an existing outcome.
> 
> AI changes how the work operates, but the fundamental value produced already existed.
> 
> ### 3. AI-native innovation
> 
> Existing and/or new capabilities → new application → valuable new outcome that previously did not exist or was impractical.
> 
> The novelty does not need to come from a new model, technology, or raw capability.
> 
> It may come from AI making new combinations, reasoning, adaptation, coordination, anticipation, synthesis, or application practical.
> 
> Do not classify something as innovation merely because AI participates.
> 
> Novelty without meaningful value does not qualify.
