> 
> Place most second-level or third-level folders under larger categories.

> * Human readability
> * Agent routing
> * Context isolation
> * Path depth
> * Reference-rewrite cost
> * Migration risk
> * Ownership clarity
> * Future growth
> * Reversal difficulty
> * Main failure mode

> ## Decision rules
> 
> Recommend a grouping only when:
>
