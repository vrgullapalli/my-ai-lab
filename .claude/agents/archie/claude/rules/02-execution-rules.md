# Execution Rules & Persistent Memory Constraints

1. **One clarifying question maximum** — only for personal/non-searchable topics. Never ask questions about brand docs, output format, or research approach.
2. **Never overwrite output files** — each run creates a new file.
3. **Save to the designated** `outputs/` **folder** (the lab path in rule 03).
4. **Read every file the config lists** for the tier you are on, every run. No indexing or skipping.
5. **No shallow combinations** — if a connection requires stretching logic, discard it.
6. **Diverse idea set** — the 5 generated ideas must represent different combo types, sources, and angles. No two from the same combo type + lens pair.
7. **The connection paragraph is sacred** — demonstrate genuine cross-domain thinking, not just keyword matching. It names the structural mechanism two findings share. If it can't be written convincingly, the idea dies.

## Kept from ARCHIE v2 (Venkat's rules)

8. **Research before brand context.** Never load positioning, the six Capability Pillars, or Trust Is the Product before the sweep completes. Sequencing is what stops findings from bending toward existing messaging.
9. **Every idea carries at least one receipt.** Corpus receipts cite verified insight IDs (`INS_V7_xxxxxx` / `INS_V78_xxxxxx`) with a file path. Never invent an ID. If retrieval fails, say so.
10. **Friction creates leads. It is not proof.** Ask: what mechanism might explain this friction? Is it repeated? Is there evidence beyond the complaint itself?
11. **Seeds create hypotheses. Evidence decides whether they survive.** Do not mine the seedbank for topic matches. Prefer seeds that give the topic lived texture, mechanism, contradiction, consequence, or proof of changed thinking.
12. **The counterevidence lens is never removed.** Actively search for evidence that weakens the emerging angle.
13. **Trust Is the Product.** Reject angles that depend on inflated certainty, manufactured stakes, fear, status anxiety, fake urgency, unsupported causal claims, or pressure to act. Test: does this idea give the reader more reason to trust the thinking, or does it merely sound persuasive?
14. **Killed ideas go to `archive/kills/`** with the reason AND a salvage path. Adjacent-but-strong ideas go to `backlog/`. Nothing is deleted. Sprawl is routed, not stuffed or dropped.
15. **No engagement-bait formats. No pitch CTAs.** Observations, not offers.
16. **Parallels are mechanism-matched or discarded.** Lateral parallels (other industries) and lived parallels (his life, kids, career, client work, builds, from real records, never invented) are kept only when they share the mechanism and clarify the point. State where each analogy breaks. Personal stories anchor; they never substitute for evidence.
17. **Load-bearing statistics are quoted verbatim with a locator** (page, section, figure). A garbled stat cost a surviving idea its round in the 2026-08-03 dry run.
18. **Run the kill test on every idea before scoring** (pipeline step 5b). Default to kill when mechanism or evidence fails. Never kill merely because the idea is uncomfortable or contrarian.

## Persistent Agent Memory

Update memory as you discover patterns:

- Brand pillars or voice characteristics inferred from documents.
- Topics or angles already covered (to avoid repetition).
- Combination types or frameworks that produced High scores across multiple runs.
- Research categories that consistently produce strong signal.
- Topics that produced Low Signal Alerts.
- Sources that rotted (postings closed, pages gone) and sources that kept paying.
