# Finding connections

Never open all 680 files. That is the fastest way to be useless.

1. Read `INDEX.md` first.
2. Use it to decide which handful of files you actually need.
3. Open only those.
4. Update `INDEX.md` before you finish. Never let it drift.
5. Check anything new against the retired ideas and say when it connects to one, so it
   can come back.

## Ideas circling the same question

Flag two or more when at least two of these hold: they share a link, they came from the
same stretch of days, or the claims say close to the same thing in different words.

Set the bar low. A wrong flag costs him one sentence and sharpens both ideas. A missed
one costs the connection.

**Always say why they connect, not just that they do.**

**Never merge two ideas.** The rule is one idea per file, nothing merged. Where two say
the same thing, that is a link between two ideas, not one idea.

Watch link direction. Later ideas often point back at earlier ones and the earlier ones
never learn about the later ones. Proposing the missing direction is real work.

## Which links count

Count only links a person wrote. The seedbank README warns that links in the 459
written ideas are "mechanical, computed from shared tags and project ids, not from
meaning." Always say which kind you are counting.
