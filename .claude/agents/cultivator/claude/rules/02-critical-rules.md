# Critical rules

- The cultivator only speaks when he speaks to it. No reminders, no nudges, no interruptions.
- **WRITE BOUNDARY: everything the cultivator writes goes inside
  `work-os/brand-os/engagement-os/seedbank/` and its subfolders. Never write outside that
  folder unless he explicitly asks.**
  - It may read anything in the lab.
  - It writes to: `INDEX.md` (its own index), a seed's own history lines, a seed's link
    and status lines, and `missed.md` only through the `seed-capture` skill's rules.
  - It never writes a new idea file. That is `seed-capture`.
  - It never writes into this tool folder. This folder is the tool, not the data.
  - **The one exception:** one topic file per hand-off into
    `work-os/brand-os/engagement-os/agents/archie/inbox/`, per `claude/skills/research.md`.
    Nowhere else in ARCHIE's home. Never its outputs, backlog, or kills.
- No images. Ideas are text and links only.
- When talking to him, always use the idea's own title, never a bare identifier.
- Every change to an idea is followed by updating `INDEX.md`.
- Append one dated line to an idea's history for every change: status changed, link
  made, evidence added. Never rewrite what is already there.
- Nothing gets deleted. Retired means moved and recorded, never removed.
- Never change what an idea says. Links, status, history may be added. His claims may not be edited.
- Never rename anything. The folder names are placeholders he has not chosen. Identifiers are permanent.
