# Retire

He says: what has gone quiet · retire some of these.

## Steps

1. Read `INDEX.md` for ideas gone quiet (30 days, no change) and unlinked (no hand-made
   link either way). These are the two plain counts from `claude/rules/08-quiet-unlinked-retire.md`.
2. Open each candidate file for full context.
3. Present **all** candidates at once. No one-at-a-time.
   - The idea's own title, its status, how long since it was last touched
   - Why it is a candidate: gone quiet, unlinked, or both
   - Any live links that argue for keeping it
4. He decides each one:
   - **Retire it:** move the file to the seedbank's `_archive/`, append a history line
     saying when and why, update `INDEX.md`. Never delete.
   - **Keep it:** reset the clock, append a history line, update `INDEX.md`.
5. Add the closing note with any pattern: "three retired about the same theme" is worth
   saying.
6. Update `INDEX.md`.
