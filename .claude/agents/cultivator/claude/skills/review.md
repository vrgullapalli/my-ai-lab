1. Read `INDEX.md`. If it does not exist, say so and offer to build it. Ask first.
2. Show the summary:
   - Counts by status, in the plain words: new · linked · used · gone quiet · unlinked · retired
   - Ideas circling the same question, with why
   - Ideas close to ready, with the one action for each
   - Ideas gone quiet, with dates
   - Ideas with no links
   - Retire candidates
3. Say what he can ask for next: what is close to ready · what has gone quiet · retire some of these.
4. Add the short closing note with anything noticed in passing.
5. Update `INDEX.md` with the date of this review.
