# Insight Quality Standard

Use this standard before selecting final insights.

- Earned-insight gates

## What counts as an insight

Keep these categories distinct:

| Category | Definition |
|---|---|
| Observation | Something explicitly stated or directly visible in the supplied material |
| Pattern | A recurring relationship across two or more observations |
| Insight | An evidence-grounded explanation or implication that changes interpretation or action |
| Hypothesis | A plausible explanation that is not yet sufficiently supported |
| Implication | A consequence that follows if an insight is true |
| Recommendation | A proposed action in response to an insight or uncertainty |

An insight is not just an interesting sentence. It must explain something and alter a consequential choice.

## Earned-insight gates

A candidate must pass all six gates:

1. **Non-restatement:** It is not already explicit in the source.
2. **Traceability:** Specific observations support it.
3. **Mechanism:** It identifies why, how, through what relationship, or with what consequence.
4. **Materiality:** It changes a belief, decision, priority, risk, opportunity, or test.
5. **Resistance:** It accounts for disconfirming evidence and survives a plausible alternative explanation, or clearly states why confidence remains limited.
6. **Distinctness:** It is not the same mechanism as another selected insight.

A candidate that fails a gate is not returned as an insight. It may be retained as an observation, unknown, or hypothesis.

## Candidate scoring

After the gates, score each surviving candidate privately from 0 to 2 on five dimensions.

| Dimension | 0 | 1 | 2 |
|---|---|---|---|
| Evidence strength | Unsupported | Partial or indirect support | Multiple specific supports or one decisive support |
| Non-obviousness | Explicit or generic | Requires some synthesis | Reframes the apparent problem or reveals a hidden mechanism |
| Decision consequence | Changes nothing material | Refines a choice | Changes direction, priority, risk, or resource allocation |
| Practical usefulness | No clear use | Suggests an area to examine | Produces a concrete action, test, or safeguard |
| Distinctness | Duplicates another candidate | Partly overlaps | Adds a separate mechanism or consequence |

Interpret totals:

- **8 to 10:** Strong candidate. Return if relevant.
- **6 to 7:** Conditional candidate. Return only when materially useful, with the limitation explicit.
- **0 to 5:** Omit as an insight.

The score is an internal selection aid. Do not show it unless the user asks.

## Stress tests

### The restatement test

Could the claim be copied directly from the source? If yes, it is an observation, not an insight.

### The source-substitution test

Could the same sentence appear in almost any strategy report after replacing the nouns? If yes, it is probably generic advice.

### The evidence-removal test

Would the claim remain unchanged if the source evidence disappeared? If yes, it is probably imported intuition rather than source-grounded analysis.

### The alternative-explanation test

Name the strongest plausible competing explanation. Compare how well each explanation accounts for the observations. Prefer the least-disconfirmed explanation, not the most rhetorically attractive one.

### The disconfirmation test

Identify evidence that weakens the candidate, does not fit it, or is non-diagnostic. If the response reports only supporting evidence, confidence is overstated.

### The decision-change test

Complete this sentence:

> If this is true, the stakeholder should reconsider ___ because ___.

If nothing material fills the blank, the candidate is not decision-relevant.

### The falsifier test

Identify what new evidence would materially weaken or overturn the claim. If no conceivable evidence could change it, the claim is too vague or unfalsifiable.

### The distinctness test

State each candidate's mechanism in five to ten words. If two mechanisms are the same, merge or remove one.

## Selection rules

- Return one to four insights. Never fill a quota.
- Rank by expected decision value, not rhetorical surprise.
- Prefer one well-supported insight over four thin ones.
- Prefer a precise medium-confidence insight over a dramatic low-confidence claim.
- Select the "insight that matters most" by consequence and evidence together.
- A counterintuitive conclusion is valuable only when it survives the same evidence standard as any other conclusion.

## When zero insights are earned

Say so directly. Separate:

- What the material supports.
- What it does not support.
- What missing evidence would make deeper analysis possible.

This is a successful analytical result, not a failure.

## Common failure modes

| Failure | Correction |
|---|---|
| Method theater | Use lenses privately; report only surviving conclusions |
| Forced novelty | Permit zero insights and remove quantity targets |
| Restatement with stronger adjectives | Require a mechanism and decision consequence |
| Speculation laundering | Label hypotheses and state missing evidence |
| Confirmation-only analysis | Identify disconfirming and non-diagnostic evidence |
| Analogy as proof | Use analogy to generate a candidate, then test against source evidence |
| Duplicate insights | Compare mechanisms, not wording |
| Generic action list | Derive each action from a specific insight or uncertainty |
| False precision | Match confidence language to evidence strength |
| Sensational language | Let consequence, not adjectives, create impact |
