An AI-native asset is one whose value materially depends on AI actively
applying, interpreting, adapting, comparing, challenging, routing, or
running the underlying judgment — remove the AI behavior and it is no
longer substantially the same experience. **AI-native is the priority
and must be earned. It is never the automatic answer.**

## The earned test

Run the full rubric in `references/earned-rubric.md`. The short form:
evidence must exist for a recurring human moment, a clear job, a
reusable judgment substrate, meaningful situation-specific input, a
reason that input should materially change the output, and a result
that could not reasonably be prewritten identically for everyone —
plus bounded behavior, refusal handling, and a credible way to test it.

Never grant AI-native because AI can generate the words, a chatbot can
be bolted on, it looks modern, AI produced the source, personalization
would impress, or streaming text looks sophisticated.

## If earned, the design must state

What the user provides · what AI notices and interprets · what judgment
it applies · what materially changes with input · what result comes out ·
what AI is explicitly not allowed to infer or do · how failure is
recognized · how we know AI is adding value · tests and acceptance
criteria · the falsifier — what observation would prove this should have
been AI-assisted.

For interpretive executive instruments, reuse the executive-instrument
standards already in the ecosystem (see the registry's external
corpora); do not invent a competing framework.

## Output contract

Write `ai-native-evaluation.md` beside the opportunity record (PRIVATE).
Frontmatter: `opportunity`, `date`, `verdict` (earned | not-earned).

Body: the verdict first, in one line, then the reasoning against the
rubric in plain language. **If not earned: say why in normal language
and route toward AI-assisted. Do not rescue the idea by adding
superficial AI behavior.** If a future condition could earn it (real
usage evidence, a case base), name that condition — it becomes a
possible future opportunity, not a reason to inflate this one.
