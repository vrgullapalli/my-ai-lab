# The AI-native earned test — full rubric

Every item is answered with evidence, not enthusiasm. An unanswered item
is a NO. A majority of YES answers does not earn the verdict — the
starred items are individually mandatory.

## Substrate (all mandatory ★)

1. ★ **Recurring human moment** — named, recognizable, evidenced from
   real work (dossiers, engagements, candidate learnings), not imagined.
2. ★ **Clear user job** — what progress the person is trying to make,
   in their words.
3. ★ **Reusable judgment underneath** — a method, rubric, or capability
   that exists independently of any single output.
4. ★ **Sufficient evidence or cases to define that judgment** — enough
   real instances that the adaptive behavior can be specified and
   bounded. A judgment defined from one case is a guess.

## The adaptive core (all mandatory ★)

5. ★ **Meaningful situation-specific input** — the user brings something
   real about their situation, not a preference toggle.
6. ★ **A reason input should change behavior** — different situations
   genuinely need different treatment, and we can say how.
7. ★ **AI performs interpretation, adaptation, comparison, interruption,
   routing, or synthesis** — actual judgment work, not retrieval or
   rephrasing.
8. ★ **The result could not reasonably be prewritten identically for
   everyone.** If a well-made static version serves every user nearly
   as well, AI-native is not earned. This is the genericity killer.

## Safety of the behavior (all mandatory ★)

9. ★ **Bounded behavior** — what it will not attempt is stated.
10. ★ **Refusal and uncertainty handling** — it can say "this input is
    outside what I can judge" and does.
11. ★ **A credible testing method** — input variation produces
    meaningful, checkable output variation; reproducibility appropriate
    to the asset type.

## Disqualifiers — any one of these alone kills the verdict

- The AI's contribution is generating the words.
- The interactivity is a chat window over static content.
- The personalization is cosmetic (name, industry label swapped in).
- The judgment substrate is the model's general knowledge, not ours —
  a generic model with a generic prompt would produce substantially
  the same result.
- The refusal behavior cannot be specified.
- No falsifier can be stated.

## Verdict

EARNED — every ★ item evidenced, no disqualifier present.
NOT EARNED — anything less. Route to AI-assisted and say what future
evidence, if any, could change the verdict.
