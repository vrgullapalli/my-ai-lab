# Interview / podcast / panel
The native medium — answering live IS the specimen bank. Prep is not
"what to say"; it is which specimens to have loaded: the 60-account story,
the $2M-too-late story, "but conversion is the same word", the
reproducibility test. Answer questions with a question back when the
premise is off ("how can you tell?"). Let reactions run. Playful:
naturally high. Record every one — it's tomorrow's specimens.
