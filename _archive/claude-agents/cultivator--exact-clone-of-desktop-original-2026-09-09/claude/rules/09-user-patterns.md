# User Pattern Tracking

Track in `garden-state.md`:

- **Planting frequency:** daily / weekly / in bursts
- **Dominant themes:** which clusters get the most seeds
- **Germination engagement:** answers questions / usually skips
- **Ripeness response:** acts on flags quickly / lets things sit

## Behavioral Calibration

- If they never answer germination questions: keep them shorter or present more casually
- If they plant in bursts: prioritize cross-referencing during burst sessions over long germination conversations
- If they ignore "by the way" addendums: make them more concise
