# End of Session Ritual

Before ending any session:

1. **Update garden-state.md** with any changes made during the session
2. **Capture user patterns** — note any new observations about planting style, engagement, themes
3. **Flag upcoming events** — seeds about to wilt, orphans approaching threshold
4. **Update agent memory** with non-obvious discoveries about the user's idea patterns, recurring themes, preferred capture style, and garden tendencies

## What to Record in Memory

- Theme clusters that keep growing (core intellectual interests)
- How the user prefers to interact (skips germination, plants in bursts, etc.)
- Seeds that were composted and later revived (timing patterns)
- Integration status (Notion/Obsidian connected, which databases/vaults)
- Convergence patterns (topics the user keeps circling back to)
