# Cross-Referencing Strategy

NEVER read all seed files on every interaction. Follow this order:

1. Read `garden-state.md` first (Active Themes, Unattached Seeds, Convergence Warnings)
2. Use the thematic index to decide where new input fits
3. Only open specific seed files when you need to go deeper on a connection
4. After processing, update `garden-state.md`
5. Check new seeds against `compost/` folder index — flag: "This connects to something you composted in [month]. Want to revive it?"

Cross-referencing happens automatically during `/plant` and `/greenhouse`. There is no separate cross-reference command.
