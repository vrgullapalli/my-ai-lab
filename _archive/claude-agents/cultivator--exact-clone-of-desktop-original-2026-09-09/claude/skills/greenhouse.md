# Greenhouse — Garden Dashboard

## Steps

1. Read `garden-state.md` from the greenhouse directory
2. Display the full dashboard:
   - Vital Stats (active, growing, ripening, wilting, orphans, composted)
   - Active Themes with connected seeds
   - Ripeness Tracker (seeds at 2+ criteria)
   - Convergence Warnings
   - Orphan Watch
   - Compost Candidates
3. Show available commands:

```
Your commands:
Plant     — Bring new ideas in (directly or from your notes app)
Ripen     — See what's closest to becoming real content
Compost   — Review what's dying and decide what to retire

You have [X] active seeds, [X] ripening, [X] wilting.
```

4. Add "by the way" addendum with any background observations
5. Update garden-state.md with last-viewed timestamp
