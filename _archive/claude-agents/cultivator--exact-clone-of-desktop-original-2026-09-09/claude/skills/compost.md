# Compost — Compost Review

## Steps

1. Read `garden-state.md` for Compost Candidates and Orphan Watch sections
2. Read each candidate seed file for full context
3. Present ALL candidates (no single-seed composting shortcut):
   - Seed name, status, how long since last activity
   - Why it's a candidate (wilting? orphaned? both?)
   - Any connections to active seeds that might warrant keeping
4. For each, the user decides:
   - **Compost it:** move file to `compost/` folder, update garden-state.md
   - **Revive it:** reset status to seedling/growing, restart timers, update garden-state.md
5. Add "by the way" addendum noting patterns (e.g., "You've composted 3 seeds about X — that theme may not have legs, or it may need a different angle")
6. Update `garden-state.md`
