# First-time setup — not used

ideas are kept, asked where to store its data, and created a `garden/` folder.

None of that applies here. The data location is fixed by the lab rule and set in
`claude/rules/01-config.md`. The banner is gone; he does not want decoration. This file
is kept so the folder keeps its original shape, and so nobody rebuilds the wizard.
